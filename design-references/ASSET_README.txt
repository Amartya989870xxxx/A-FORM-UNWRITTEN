# A FORM UNWRITTEN — Reference Assets

Copy this `public` folder into the root of the existing Phaser/Vite project.

Files:
- `character-concept.png`: the original paired concept. The right-hand charcoal/gold figure is the ordinary visible protagonist; the left cyan figure is hidden astral lore only.
- `playable-garment-reference.png`: isolated crop of the right-hand charcoal/gold garment concept. This is a visual reference, NOT an animation-ready sprite sheet.
- `shattered-verge-reference.png`: environment and atmosphere direction.
- `foreground-depth-reference.png`: foreground, architecture and depth reference.
- `world-atlas-reference.png`: world-map composition reference. Treat the shrouded land as undiscovered; do not reveal it through ordinary map exploration.

Do not use any of these full images as a single background behind interactive gameplay. They are visual references for creating properly layered assets.
